Launchpad

A launcher and taskbar for Windows. Keep your portable apps, scripts, dev commands, websites and games on one grid, with window snapping and a full-screen media library.

Download for Windows

Windows 10 or 11 · Free and open source · View on GitHub

What it does

Launch anything

Programs, files, folders, websites, Python or Node scripts and shell commands. Shortcuts resolve to their real target.

Files that stay put

Drop a file or folder from Explorer and Launchpad keeps its own copy, with thumbnails for pictures, so it still opens after the original is moved.

Freeform grid

Place items anywhere. Group them into nested, collapsible, colored islands, and select several at once with a drag box.

Taskbar

Pinned items, open windows, search across everything, and tray widgets for volume, Wi-Fi, Bluetooth, USB eject, clock and power.

Window snapping

Snap windows to halves, thirds, quarters and more. Use the grid placer (Ctrl+Alt+G), your own layouts, or saved scenes that put every window back in place.

Media library

A full-screen library of games and videos, built for the couch. Use a controller or keyboard, launch each title in the emulator or player you choose, and give every title its own artwork.

Look and feel

Dock the taskbar to any edge, pick light or dark, set an accent color, choose translucent or transparent bars, and add a wallpaper.

Backups and updates

Export and import your whole setup, icons, layouts and scenes included. Updates install from inside the app.

Install

  1. Download Launchpad-Setup-<version>.exe from the latest release.
  2. Run it. The installer isn't code-signed, so Windows SmartScreen may warn you. Click More info, then Run anyway.
  3. Press Ctrl+Space to show or hide Launchpad from anywhere. Closing the window sends it to the tray.

Launchpad checks GitHub for updates and can install them for you. Your data stays on your PC in %APPDATA%\launchpad.

Build it yourself

Needs Windows 10 or 11 and Node.js 22 or newer. Clone the repository, then run npm install and npm start. Full instructions are in the README.
